# DataLab

VSM(M-H 루프)·XRD 결과를 해석하고 논문·PPT용 그래프를 그리는 Windows 프로그램. 개발자 KIM YEONGDO.

## 설치·업데이트
1. [릴리스](https://github.com/Dubitnarae/DataLab/releases/latest)에서 `DataLab_v<버전>.zip`을 받아 **쓰기 가능한 폴더**(예: 문서)에 풀고 `DataLab\DataLab.exe`를 실행한다. 설치 과정은 없다.
2. 실행할 때마다 새 버전을 확인하고, 있으면 「지금 업데이트」 한 번으로 바꾼 뒤 다시 연다(**도움말 › 업데이트 확인**으로도 됨). 받은 파일은 SHA256으로 확인하고, 실패하면 이전 버전을 그대로 둔다.
3. 데이터(DB·원본 사본·템플릿)는 `문서\DataLab_Data`에 있어 업데이트해도 그대로다.
4. 인터넷 대신 공유 폴더에서 받으려면 `%APPDATA%\datalab\update.json`에 `{"folder": "\\\\NAS\\공유\\DataLab"}`처럼 적고, 그 폴더에 zip과 `.zip.sha256`을 둔다.

## 쓰는 법
1. `DataLab.exe` 실행 → 파일을 창에 끌어다 놓거나 **파일 › 열기**(폴더도 됨).
2. 왼쪽 위에서 **VSM / XRD**를 고르고, 목록에서 체크한 시료만 겹쳐 그린다.
3. 오른쪽에서 스타일(PPT용·논문 1단 8.5 cm·논문 2단 17.5 cm), 원점 확대 인셋, H 단위(Oe·kA/m), 자장 오프셋 보정, XRD 세로 띄우기를 바꾼다.
4. **파일 › 그림 저장**: PNG·TIF 600 dpi, SVG·PDF·EPS 벡터. **Ctrl+Shift+C**: 그림을 클립보드로(PPT에 바로 붙여넣기).
5. **결과 표 복사**: Excel에 붙여넣기.
6. 그래프 편집 탭: 축 범위·눈금·로그·제목(수식)·범례(순서 뒤집기)·선 색/굵기/기호, 2·4·9 패널·세로 쌓기, 패널별 축, 오른쪽 Y축, 주석·화살표, 오차 막대. 목록 ▲▼로 그리는 순서. 템플릿으로 저장해 다시 쓴다.
8. 맨 위 탭
   - **데이터 처리**: 해석 구간, 튀는 점 찾아 빼기, 기준 곡선(빈 홀더) 빼기, 평활화 → 「적용」하면 그래프·결과 표에 반영(원본 파일은 그대로). 적분·보간
   - **피크 피팅**: Gauss·Lorentz·pseudo-Voigt·Pearson VII 여러 개 + 바탕선, 중심·반치폭·넓이 ± 오차, 잔차
   - **자기 포화 피팅**(VSM): 랑주뱅 함수, 포화 접근 법칙
   - **워크시트**: 데이터 표 보기·복사·CSV, 식(예: `y / 0.0123`)으로 새 시료 만들기
9. **파일 › 체크한 시료 DB에 저장**(Ctrl+D) → **DB 목록·태깅**(Ctrl+L): 시료 검색·태그, 결과 비교표·Excel, NAS 백업·병합.

## 읽는 파일
- VSM: Lake Shore 8600 csv(장비 계산값과 다시 계산한 값을 대조), 옛 IDEAS VSM txt, 숫자 2열 텍스트(첫 열 H, 둘째 열 M)
- XRD: .xrdml, .rasx, X'Pert csv, 2열 텍스트 — 판정·피크·결정립 크기는 [xrdcheck](https://github.com/Dubitnarae/xrd-amorph-checker) 결과를 그대로 보여 준다.

## VSM 계산
- Hc: M이 0을 지나는 자장들의 절댓값 평균(장비와 같은 식). 루프가 치우치면 반폭과 치우침(H 바이어스)을 함께 표시
- Mr: H가 0을 지날 때 M들의 절댓값 평균, Ms: (M 최대 − 최소)/2, 각형비 Mr/Ms
- 자장 오프셋 보정: 입력한 값만큼 H를 옮겨 계산하고 보정 전 Hc도 함께 표시
